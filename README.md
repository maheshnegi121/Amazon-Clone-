# Amazon Clone – HTML & CSS

Developed a responsive Amazon-inspired e-commerce website using HTML5 and CSS3. The project recreates the core visual design of Amazon, including a navigation bar, search section, product categories, product cards, promotional banners, and footer sections.

Technologies Used: HTML5, CSS3

Key Features:

Amazon-style navigation bar and search bar
Product category sections
Responsive product cards and layouts
Promotional banners and shopping sections
Footer with multiple navigation links
Flexbox and CSS Grid for page layout
Responsive design for different screen sizes
Hover effects and styling for better user experience

This project helped strengthen my understanding of HTML structure, CSS styling, Flexbox, Grid, positioning, spacing, and responsive web design.

Current Status: 
The current version focuses on the frontend interface only. JavaScript functionality has not been added yet. The project is still under development and will be updated with more features and functionality in the future.5
